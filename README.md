# 🎮 Pong Game

A classic Pong arcade game built with vanilla HTML, CSS, and JavaScript. Play against an AI opponent in this retro-inspired implementation.

## 🚀 Play Online

Play the game here: https://samuel-calderonle.github.io/pong-game/

## 🎯 How to Play

- Move the left paddle with your mouse or the Up/Down arrow keys
- The right paddle is controlled by the computer
- Score by getting the ball past the opponent
- The ball bounces off the walls and paddles

## ✨ Features

- Mouse and keyboard controls
- AI opponent
- Ball physics and collision detection
- Scoreboard
- Smooth canvas-based animation
- Simple, dependency-free setup

## 🛠️ Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/samuel-calderonle/pong-game.git
   cd pong-game
   ```
2. Open `index.html` in a browser
